## 조건문 / 반복문

```python
# Python
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("F")

for i in range(5):
    print(i)

for fruit in fruits:
    print(fruit)

while count < 3:
    count += 1
```

```javascript
// JavaScript
if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else {
  console.log("F");
}

for (let i = 0; i < 5; i++) {
  console.log(i);
}

for (const fruit of fruits) {
  console.log(fruit);
}

while (count < 3) {
  count++;
}
```

### 컴프리헨션 → map / filter

```python
# Python
doubled = [x * 2 for x in nums]
evens   = [x for x in nums if x % 2 == 0]
total   = sum(nums)
```

```javascript
// JavaScript
const doubled = nums.map((x) => x * 2);
const evens   = nums.filter((x) => x % 2 === 0);
const total   = nums.reduce((a, b) => a + b, 0);
```

## 파이썬에는 있는데 자바스크립트에 없는 것

- **음수 인덱스** `arr[-1]` → `arr.at(-1)` 로 대체
- **몫 연산자** `//` → `Math.floor()`
- **튜플** → 배열로 대체
- **`sum()`** → `reduce()`
- **`range()`** → 일반 for 문
- **f-string의 서식 지정** `f"{x:.2f}"` → `x.toFixed(2)`

## 자바스크립트에만 있는 것

- **`undefined`** — 값을 아직 안 넣은 상태
- **`===` 와 `==`** — 반드시 `===` 를 쓰세요
- **화살표 함수** `(a) => a * 2`
- **DOM 조작** — 웹 화면을 직접 고칠 수 있음 (파이썬으로는 불가능)
- **`async` / `await`** — 파이썬에도 있지만 JS에서 훨씬 자주 씁니다

---

## 함정 5가지 (한 번씩은 꼭 당합니다)

1. **`"10" + 5` 는 `"105"`** — 입력값은 항상 문자열. `Number()` 로 바꾸세요.
2. **`==` 는 타입을 무시** — `0 == false` 가 `true`. 항상 `===`.
3. **`[10, 9, 100].sort()` 는 `[10, 100, 9]`** — 숫자 정렬은 `sort((a,b) => a-b)`.
4. **빈 배열 `[]` 는 truthy** — 파이썬과 반대. 비었는지는 `arr.length === 0`.
5. **`const` 배열의 내용은 바뀝니다** — 재할당만 막을 뿐입니다.
