# 00. 자바스크립트 실행 환경

## 1. 자바스크립트란

- **웹 브라우저 안에서 도는 유일한 프로그래밍 언어**입니다.
  버튼을 눌렀을 때 뭔가 일어나는 것, 스크롤하면 애니메이션이 나오는 것 —
  전부 자바스크립트입니다.
- 요즘은 **Node.js** 덕분에 브라우저 밖(서버, CLI 도구)에서도 씁니다.
- 이름이 Java와 비슷하지만 **Java와는 아무 관계가 없습니다.**
  (인도와 인도네시아 정도의 관계입니다.)

### 왜 배우나

파이썬을 배웠는데 왜 또 다른 언어를 배우느냐 하면:

| | Python | JavaScript |
|---|---|---|
| 강점 | 데이터 분석, AI, 자동화, 백엔드 | 웹 화면(프론트엔드), 웹 서버 |
| 못 하는 것 | **브라우저에서 못 돎** | (무겁고 어려운 수치 연산) |

즉 **웹 화면을 만들려면 자바스크립트가 유일한 선택지**입니다.
파이썬으로 만든 API를 화면에 붙이려면 결국 필요합니다.

---

## 2. 실행 방법 3가지

### 방법 A. 브라우저 콘솔 (가장 빠름 — 오늘 주로 씀)

1. 크롬을 열고 아무 페이지에서 **F12** (또는 `Ctrl + Shift + J`)
2. 상단 **Console** 탭 클릭
3. 코드를 치고 Enter

```javascript
console.log("안녕하세요");
```

파이썬의 대화형 셸(`>>>`)과 같습니다. 설치가 필요 없습니다.

> **여러 줄 쓰기**: 콘솔에서 줄바꿈은 `Shift + Enter` 입니다.
> 그냥 Enter를 누르면 바로 실행됩니다.

---

### 방법 B. HTML 파일에 넣고 브라우저로 열기

`test.html` 파일을 만들고:

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>JS 연습</title>
</head>
<body>
  <h1>안녕하세요</h1>

  <script>
    console.log("스크립트가 실행되었습니다");
  </script>
</body>
</html>
```

파일을 더블클릭하면 브라우저에서 열립니다. F12 → Console에서 결과 확인.

**외부 파일로 분리**하는 것이 정석입니다.

```html
  <script src="app.js"></script>
```

> `<script>` 는 **`</body>` 바로 위**에 두세요.
> 위쪽에 두면 HTML이 다 그려지기 전에 실행돼서 요소를 못 찾습니다.

---

### 방법 C. Node.js (파이썬처럼 터미널에서 실행)

1. https://nodejs.org → **LTS** 버전 설치 (Next만 누르면 됩니다)
2. 터미널에서 확인:

```bash
node --version
```

3. `.js` 파일 실행:

```bash
node 01_변수와_출력.js
```

파이썬의 `python 파일.py` 와 똑같습니다.
**이 폴더의 `.js` 파일들은 전부 이 방식으로 실행할 수 있습니다.**

---

## 3. 출력 — `console.log`

파이썬의 `print()` 자리에 `console.log()` 를 씁니다.

```javascript
console.log("안녕");           // 안녕
console.log(1, 2, 3);          // 1 2 3
console.log("값:", 10);        // 값: 10
```

브라우저 콘솔에서만 쓸 수 있는 것들:

```javascript
console.table([{name: "홍길동", age: 20}]);  // 표로 예쁘게
console.error("에러 메시지");                 // 빨간색
console.warn("경고");                        // 노란색
```

## 4. 파이썬과 다른 문법 3가지 (미리 알아두기)

### (1) 문장 끝에 세미콜론 `;`

```javascript
let a = 1;
let b = 2;
```

없어도 대부분 동작하지만, **붙이는 습관**을 권합니다.

### (2) 블록은 들여쓰기가 아니라 중괄호 `{}`

```python
# Python
if score >= 90:
    print("A")
```

```javascript
// JavaScript
if (score >= 90) {
  console.log("A");
}
```

자바스크립트는 들여쓰기를 안 해도 돌아갑니다.
하지만 **읽기 위해** 반드시 들여쓰세요.

### (3) 주석

```javascript
// 한 줄 주석 (파이썬의 #)

/*
  여러 줄 주석
*/
```
