# 02. 설치와 초기 설정

## 1. Git 설치

### Windows

1. https://git-scm.com/download/win 접속 → 자동으로 설치 파일이 내려받아집니다.
2. 실행 후 **모든 옵션을 기본값으로 두고 Next만 계속 누릅니다.**
   - 중간에 기본 에디터를 고르는 화면이 나옵니다. 그냥 두면 됩니다.
   - "Adjusting your PATH environment" 는 반드시 가운데 **권장 옵션** 유지.
3. 설치가 끝나면 **Git Bash** 라는 프로그램이 같이 깔립니다.

### macOS

터미널에 아래를 입력하면 설치 안내가 뜹니다.

```bash
git --version
```

이미 깔려 있는 경우가 많습니다. 없다면 안내에 따라 설치하세요.

---

## 2. 설치 확인

터미널(Windows는 **PowerShell** 또는 **Git Bash**)을 열고:

```bash
git --version
```

```
git version 2.45.2.windows.1
```

이런 식으로 버전이 나오면 성공입니다.

> `'git' 은(는) 내부 또는 외부 명령... 이 아닙니다` 라고 나오면
> 설치가 안 됐거나, **터미널을 껐다 다시 켜지 않은 것**입니다. 껐다 켜 보세요.

---

## 3. 내 이름과 이메일 등록 (딱 한 번만)

Git은 커밋마다 "누가 했는지"를 기록합니다. 그래서 먼저 알려줘야 합니다.

```bash
git config --global user.name "홍길동"
```

```bash
git config --global user.email "hong@example.com"
```

- `--global` 은 "이 컴퓨터 전체에 적용" 이라는 뜻입니다. 한 번만 하면 됩니다.
- **이메일은 GitHub 가입 이메일과 똑같이** 쓰세요.
  다르면 커밋이 내 GitHub 계정과 연결되지 않아 잔디가 안 심어집니다.

### 잘 들어갔는지 확인

```bash
git config --global --list
```

```
user.name=홍길동
user.email=hong@example.com
```

## 4. 기본 브랜치 이름 통일

예전 Git은 기본 브랜치 이름이 `master`, 요즘은 `main` 입니다.
GitHub는 `main`을 쓰므로 맞춰 둡니다.

```bash
git config --global init.defaultBranch main
```

## 5. 한글 파일명 깨짐 방지 (Windows 권장)

```bash
git config --global core.quotepath false
```

이걸 안 하면 `git status`에서 한글 파일명이 `\355\225\234...` 처럼 나옵니다.

## 6. GitHub 회원가입

1. https://github.com 접속 → **Sign up**
2. 이메일 / 비밀번호 / **Username** 입력
   - Username은 나중에 저장소 주소가 됩니다: `github.com/`**`내아이디`**`/레포이름`
   - 이력서에 넣을 주소이니 **알아보기 쉬운 영문 아이디**를 권합니다.
     (`xXx_darkangel_xXx` 보다는 `gildong-hong` 이 낫습니다.)
3. 이메일 인증까지 완료합니다.

## 7. 로그인 방식 — 비밀번호는 안 됩니다

2021년부터 GitHub는 **비밀번호로 push를 허용하지 않습니다.**
방법은 두 가지입니다. 오늘은 **A안**으로 갑니다.

### A안. Git Credential Manager (초보자 권장)

Windows용 Git을 설치하면 **자동으로 같이 설치됩니다.**
처음 `git push` 할 때 브라우저 창이 뜨고, 거기서 GitHub 로그인만 하면 끝입니다.
한 번 로그인하면 다음부터는 안 물어봅니다.

### B안. Personal Access Token (PAT)

브라우저 창이 안 뜨거나 A안이 실패할 때 씁니다.

1. GitHub → 우측 상단 프로필 → **Settings**
2. 맨 아래 **Developer settings**
3. **Personal access tokens → Tokens (classic)** → **Generate new token (classic)**
4. Note: 아무 이름 / Expiration: 90 days / **repo 체크박스에 체크**
5. Generate token → **화면에 뜬 문자열을 복사해서 메모장에 저장**
   - 이 창을 닫으면 **다시는 볼 수 없습니다.**
6. `git push` 할 때 비밀번호를 물으면 **이 토큰을 붙여넣습니다.**

> 토큰은 비밀번호와 같습니다. 카톡·코드·커밋에 절대 남기지 마세요.
> 5일차에 배운 `.env` 와 똑같은 원칙입니다.

## 8. 터미널 기본 명령어 복습

Git은 터미널에서 씁니다. 최소한 이 4개는 필요합니다.

| 명령 | 뜻 | 예시 |
|---|---|---|
| `cd` | 폴더 이동 (change directory) | `cd Desktop` |
| `cd ..` | 상위 폴더로 | `cd ..` |
| `ls` (Windows: `dir`) | 현재 폴더 목록 보기 | `ls` |
| `pwd` | 지금 내가 어디인지 | `pwd` |

> **팁**: 폴더 이름에 한글이나 띄어쓰기가 있으면 따옴표로 감싸세요.
> `cd "내 문서"`

> **더 편한 방법**: 탐색기에서 원하는 폴더로 들어간 뒤,
> 주소창에 `cmd` 를 치고 Enter → 그 폴더에서 터미널이 열립니다.
> (또는 폴더 빈 곳에서 마우스 우클릭 → "Git Bash Here")
