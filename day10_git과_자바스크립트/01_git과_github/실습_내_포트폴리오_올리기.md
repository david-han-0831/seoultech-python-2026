# 실습 — 2주간 만든 코드를 내 GitHub에 올리기

**목표**: 오늘 수업이 끝났을 때, 이력서에 적을 수 있는 GitHub 저장소 주소가 하나 생깁니다.

소요 시간: 약 40분

---

## STEP 1. 올릴 폴더 정리 (5분)

지금까지 실습한 파이썬 파일들을 한 폴더에 모읍니다.

```
python-study/
├── day01/
│   └── (1일차에 만든 .py 파일들)
├── day02/
├── day03/
├── day04/
└── day05/
```

- 폴더 이름은 영문 소문자 + 하이픈을 권합니다. (`python-study`, `seoultech-python`)
- 실행이 안 되는 파일, 이름이 `테스트2_진짜.py` 같은 파일은 지우거나 정리하세요.
  **남에게 보여줄 폴더**라는 걸 잊지 마세요.

---

## STEP 2. 저장소 시작 (3분)

터미널을 열고 그 폴더로 이동합니다.

```bash
cd Desktop/python-study
```

```bash
git init
```

```bash
git status
```

파일들이 빨간색(Untracked)으로 보이면 정상입니다.

---

## STEP 3. `.gitignore` 만들기 (5분)

**커밋하기 전에** 반드시 먼저 합니다.

폴더 안에 `.gitignore` 파일을 만들고 아래를 붙여넣으세요.
(메모장으로 만들 때는 "모든 파일" 형식으로 저장해야 `.gitignore.txt` 가 안 됩니다.)

```
# 환경변수 — API 키가 들어있음
.env

# 파이썬
venv/
__pycache__/
*.pyc

# OS
.DS_Store
Thumbs.db

# 에디터
.vscode/
.idea/
```

만든 뒤 확인:

```bash
git status
```

`venv/` 나 `.env` 가 목록에 **안 보여야** 성공입니다.

---

## STEP 4. 첫 커밋 (3분)

```bash
git add .
```

```bash
git status
```

⚠️ **여기서 목록을 꼭 눈으로 확인하세요.** `.env` 나 `venv/` 가 초록색으로 있으면
STEP 3이 잘못된 것입니다. `git restore --staged .` 로 취소하고 다시 하세요.

```bash
git commit -m "파이썬 특강 1주차 실습 코드 추가"
```

---

## STEP 5. README.md 쓰기 (10분) ← **가장 중요**

이게 여러분 저장소의 얼굴입니다. 아래를 복사해서 **자기 내용으로 채우세요.**

```markdown
# Python 학습 기록

서울과학기술대학교 Python 비교과 특강(2026.8.3 ~ 8.14)에서 진행한 실습 코드입니다.

## 무엇을 배웠나

- 변수, 자료형, 리스트/딕셔너리 등 기본 자료구조
- 조건문·반복문과 기초 알고리즘(정렬, 탐색)
- 함수와 클래스를 이용한 코드 구조화
- 파일 입출력, 예외 처리
- HTTP/API 이해, requests를 이용한 공공데이터 수집
- BeautifulSoup을 이용한 웹 크롤링

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `day01` | 변수, 입출력, 자료형, 기본 자료구조 |
| `day02` | 조건문, 반복문, 정렬 알고리즘 |
| `day03` | 함수, 중첩 자료구조 |
| `day04` | 클래스, 예외처리, 파일 입출력 |
| `day05` | HTTP/API, 공공데이터, 크롤링 |

## 실행 방법

​```bash

​```

## STEP 6. GitHub에 올리기 (10분)

### 6-1. GitHub에서 빈 저장소 생성

- https://github.com → `+` → **New repository**
- Repository name: `python-study`
- **Public**
- ⚠️ **README / .gitignore / license 전부 체크 해제**
- **Create repository**

### 6-2. 연결하고 push

```bash
git remote add origin https://github.com/내아이디/python-study.git
```

```bash
git push -u origin main
```

브라우저 로그인 창이 뜨면 로그인하세요.

### 6-3. 확인

GitHub 저장소 페이지를 새로고침 → 파일 목록과 README가 예쁘게 보이면 **완료**입니다.

---

## STEP 7. 마무리 점검

- [ ] 저장소가 **Public** 이다
- [ ] README가 첫 화면에 렌더링되어 보인다
- [ ] `.env`, `venv/` 가 올라가지 않았다
- [ ] 커밋 메시지가 `수정`, `ㅁㄴㅇㄹ` 가 아니다
- [ ] 저장소 주소를 메모해 두었다 → `https://github.com/______/python-study`

## 도전 과제 (시간이 남으면)

1. **브랜치로 README 개선하기**
   - `git switch -c docs/readme`
   - README에 스크린샷을 추가하고 커밋
   - push → GitHub에서 **PR 생성** → merge
2. **저장소에 Topics 달기**
   - 저장소 우측 About 옆 톱니바퀴 → `python`, `study`, `api` 등 추가
   - 검색에 노출되고 정리되어 보입니다.
3. **프로필 저장소 만들기**
   - GitHub 아이디와 같은 이름의 Public 저장소 생성 + README 체크
   - 자기소개를 작성 → 프로필 첫 화면이 됩니다.
4. **오늘부터 매일 커밋하기**
   - 아무리 작아도 좋습니다. 잔디가 쌓이면 그 자체가 성실함의 증거입니다.
