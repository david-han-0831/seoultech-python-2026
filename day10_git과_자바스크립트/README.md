## 오늘 꼭 가져갈 것

### Git — 이 4줄

```bash
git status
git add .
git commit -m "무엇을 왜 바꿨는지"
git push
```

막히면 **`git status`** 부터. 90%는 거기에 답이 있습니다.

### JavaScript — 이 세 가지

```javascript
const 이름 = 값;                        // 일단 const, 바꿔야 하면 let
arr.map(x => ...)  arr.filter(x => ...)  // 배열은 이 둘로 거의 다 됩니다
document.querySelector("#id").addEventListener("click", () => {});

const res = await fetch(url);            // 오래 걸리는 일은 await
const data = await res.json();           // 그 함수 앞에는 async
```

`===` 를 쓰고 `==` 는 쓰지 마세요.

### 비동기 — 한 문단 요약

자바스크립트는 **일하는 사람이 한 명**입니다. 서버 응답을 동기로 기다리면
그동안 화면이 통째로 얼어붙습니다. 그래서 오래 걸리는 일은 **맡겨두고 먼저 진행**한 뒤,
끝나면 그때 처리합니다. 그 "끝나면 실행할 함수"가 **콜백**이고,
콜백이 겹겹이 쌓이는 문제를 푼 것이 **Promise**,
그걸 동기 코드처럼 읽히게 만든 것이 **`async`/`await`** 입니다.

> 새로 짤 때는 `async`/`await` 만 쓰면 됩니다.
> 콜백과 `.then()` 은 **남의 코드를 읽기 위해** 알아둡니다.
