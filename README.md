## 실행 방법

### 1. 파이썬 설치 확인

터미널(윈도우는 PowerShell)에서 아래를 입력했을 때 버전이 나오면 됩니다.

```bash
python --version
```

`3.10` 이상을 권장합니다.

### 2. 저장소 내려받기

```bash
git clone https://github.com/david-han-0831/seoultech-python-2026.git
```

### 3. 가상환경 만들기 (권장)

```bash
python -m venv venv
```

만든 뒤 활성화합니다.

```bash
venv\Scripts\activate
```

macOS / Linux는 `source venv/bin/activate` 입니다.

### 4. 라이브러리 설치

1~4일차는 표준 라이브러리만 쓰므로 설치가 필요 없습니다.
5일차(API·크롤링)부터 아래를 실행하세요.

```bash
pip install -r requirements.txt
```

### 5. 예제 실행

```bash
python day01_기초문법/01_변수와_출력.py
```

## 폴더 규칙

- `01_`, `02_` … 숫자 순서대로 수업이 진행됩니다.
- `실습_` 으로 시작하는 파일은 그날 배운 내용을 모아 만드는 결과물입니다.
- 모든 파일은 **혼자 실행해도 동작**하도록 작성되어 있습니다. 위에서부터 읽으며 직접 고쳐 보세요.
- 각 파일 맨 아래 `연습 문제` 주석이 있습니다. 답을 보기 전에 먼저 풀어 보길 권합니다.

## API 키 안내 (5일차)

5일차 예제 중 공공데이터포털·Gemini API는 개인 키가 필요합니다.
`.env.example`을 복사해 `.env`로 만든 뒤 발급받은 키를 채워 넣으세요.

```bash
copy .env.example .env
```

`.env` 파일은 `.gitignore`에 등록되어 있어 깃허브에 올라가지 않습니다.
**키를 코드에 직접 적어 커밋하지 마세요.**
